# WatchLab — отчёт о релизной проверке (P5)

ата проверки: 2026-11-26
бласть: финальная подготовка WatchLab Desktop, этапы P0–P5.

## тоговый вердикт

ункциональные проверки Go backend, Python-инструментов, изолированной
демонстрации и основных сценариев GUI завершились успешно в указанной
Linux-среде.

роект **не следует называть полностью проверенным**: P5 включал
функциональные проверки GUI под Xvfb, но не полноценную ручную визуальную
проверку всех страниц на реальном пользовательском дисплее.

осле P5 GUI был запущен и осмотрен в реальной сессии Linux Niri.
тот осмотр подтверждает запуск окна и позволяет оценить Dashboard,
но не заменяет полную визуальную проверку всех страниц.

## елостность данных

о время P5-проверок:

  относительно исходной базы контрольных сумм;

очистка документации изменила состав некоторых файлов в `reports/verification/`.

## сторическая проверка релизного архива

редыдущий `WatchLab-Release.zip` был отдельно проверен на распакованной
копии.  той версии архива успешно прошли Go build/test, Python compile,
81 Python-тест, Demo и функциональная проверка GUI под Xvfb.

днако состав этого ZIP больше не соответствует текущему очищенному
дереву проекта:

- старые скриншоты GUI были удалены;
- устаревшая инструкция Recover удалена;
- старые verification-файлы частично удалены или перемещены в history;
- документация релиза обновляется отдельно.

оэтому старый ZIP нельзя считать актуальным дистрибутивом после изменений.
еред публикацией нового релиза его необходимо пересобрать и повторно проверить.

## FAIL

 финальном P5-прогоне зарегистрированных провалов не указано.

олее ранний неуспешный GUI-прогон сохранён отдельно:
`reports/verification/history/gui_demo_path_check.txt`.
н является историческим результатом, а не результатом финального P5-прогона.

## граничения и непроверенные области

- дин локальный single-member etcd.
- становка клиентского процесса вместо сетевого partition.
- ет проверки multi-node кластера, выборов лидера и кворума.
- ет проверки Range pagination.
- изкое покрытие Go unit-тестами.
- n=3 на размер в основной аналитической выборке.
- ет оснований делать выводы о статистической значимости или универсальной
  производительности.
- олноценная ручная визуальная проверка всех страниц GUI не завершена.
- Windows 10/11 и macOS не проверялись; Windows `.exe` не собирался.

## ывод

P5 подтвердил работоспособность исследовательского стенда в проверенной
Linux-среде для заявленных сценариев: reconnect, compaction recovery,
валидации событий и просмотра аналитических результатов.

Текущая версия подходит для воспроизводимой демонстрации и дальнейшего
развития. убличный релиз с поддержкой Windows или гарантией полной
визуальной проверки пока не заявляется.
